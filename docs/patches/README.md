# Runtime patches (excerpts)

The repository used for this work has **no baseline commit**, so `git diff` cannot produce an
applyable patch set. Instead this folder documents the exact files and hunks that were changed,
so they can be reproduced by hand or compared against an upstream checkout of PS2Recomp.

Full context and reasoning: [`../TECHNICAL-NOTES.md`](../TECHNICAL-NOTES.md).
